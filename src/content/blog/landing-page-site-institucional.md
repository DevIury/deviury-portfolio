Muitos empresários em Curvelo têm dúvida: é melhor criar uma landing page ou um site institucional? A resposta depende do seu objetivo.

## O Que é uma Landing Page?

Uma landing page é uma página única focada em uma única ação. Por exemplo:
- Preencher um formulário
- Fazer um pedido
- Agendar um serviço

**Características:**
- Página única e objetiva
- Foco em uma conversão específica
- Sem menu de navegação complexo
- Ideal para promoções e captação de leads

## O Que é um Site Institucional?

Um site institucional é mais completo, com várias páginas:
- Página inicial
- Sobre a empresa
- Serviços
- Contato

**Características:**
- Várias páginas
- Apresentação completa da empresa
- Mais informações e conteúdo
- Ideal para empresas que querem presença online completa

## Quando Usar Cada Um?

### Use Landing Page quando:
- Quer divulgar uma promoção específica
- Precisa capturar leads para uma campanha
- Tem um produto ou serviço para lançar
- Quer testar um novo serviço

### Use Site Institucional quando:
- Quer presença online completa
- Sua empresa tem vários serviços
- Quer transmitir credibilidade
- Precisa de várias páginas com informações

## Qual a Melhor Opção?

Não existe "melhor" — existe o que é certo para cada situação. Se você não tem nenhum comece, um site institucional é mais completo. Se já tem presença digital e quer focar em uma campanha, uma landing page é ideal.
